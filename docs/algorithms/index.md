# アルゴリズム

アルゴリズムは、コンピューターに「どう考えて動けばよいか」を教える手順です。

Code Recipe では、身近なたとえ、図解、コピペで試せるコードをセットにして学びます。

この章のコード例は、すべて **Python** で統一しています。まずはPythonで考え方をつかみ、慣れてきたら他の言語にも応用してみましょう。

## ソートアルゴリズム

データを順番に並べ替えるアルゴリズムです。プログラミングでは、この並び替えを「ソート」と呼びます。

- [バブルソート: 背比べで順番をそろえよう](./bubble-sort)
- [選択ソート: いちばん小さいカードを選び続けよう](./selection-sort)
- [挿入ソート: 手札をそろえるように並べよう](./insertion-sort)
- [クイックソート: 最強の並び替えを攻略せよ](./quick-sort)
- [マージソート: 小分けにしてから合体しよう](./merge-sort)
- [ヒープソート: 山のルールで最大値を取り出そう](./heap-sort)

- [キュー: 先に並んだものから取り出そう](./queue)

## 探索アルゴリズム

- [線形探索: 先頭から順番に探そう](./linear-search)
- [二分探索: 半分ずつしぼって探そう](./binary-search)

- [ワーシャル・フロイド法: 全地点どうしの最短距離をまとめて出そう](./warshall-floyd)
