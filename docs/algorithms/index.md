# アルゴリズム

アルゴリズムは、コンピューターに「どう考えて動けばよいか」を教える手順です。

Code Recipe では、身近なたとえ、図解、コピペで試せるコードをセットにして学びます。

## ソートアルゴリズム

データを順番に並べ替えるアルゴリズムです。プログラミングでは、この並び替えを「ソート」と呼びます。

- [バブルソート: 背比べで順番をそろえよう](./bubble-sort)
- [選択ソート: いちばん小さいカードを選び続けよう](./selection-sort)
- [挿入ソート: 手札をそろえるように並べよう](./insertion-sort)
- [クイックソート: 最強の並び替えを攻略せよ](./quick-sort)
- [ヒープソート: 山のルールで最大値を取り出そう](./heap-sort)

## 探索アルゴリズム

データの中から、目的の値や条件に合うものを見つけるアルゴリズムです。まずは「順番に探す」と「半分ずつしぼる」の違いをつかみましょう。

- [線形探索: 先頭から順番に探そう](./linear-search)
- [二分探索: 半分ずつしぼって探そう](./binary-search)

## グラフ探索

点と線でつながった情報をたどるアルゴリズムです。迷路、地図、SNSのつながりのようなデータを考えるときに使います。

- [深さ優先探索法: 行けるところまで進もう](./depth-first-search)
- [幅優先探索法: 近いところから広げよう](./breadth-first-search)

## 数学アルゴリズム

数の性質を利用して、計算を効率よく進めるアルゴリズムです。素数や約数など、数学とプログラミングがつながる単元です。

- [エラトステネスの篩: 素数をまとめて見つけよう](./sieve-of-eratosthenes)

## 発展

少し大きな問題を、小さな問題に分けて考えるアルゴリズムです。ゲーム、最短ルート、最適な組み合わせなどにつながります。

- [動的計画法: 小さな答えを再利用しよう](./dynamic-programming)
