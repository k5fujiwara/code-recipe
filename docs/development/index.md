# 開発フロー

ここでは、プログラミング塾生が「登録する」「作る」「公開する」「直す」をくり返すためのレシピをまとめます。

まずは、開発でよく使うサービスの登録方法や、SNS・API連携の準備から確認しましょう。

## レシピの進め方

1. 完成形をまねする
2. コードを少し変えて結果を見る
3. 自分の言葉で仕組みを説明する
4. 自分だけの作品に作り替える
