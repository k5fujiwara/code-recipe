# お問い合わせ

Code Recipe へのお問い合わせ、内容の修正依頼、掲載内容に関するご連絡は、以下の窓口からお願いいたします。

## お問い合わせ方法

**Google フォーム** からお送りください。

- [お問い合わせフォームを開く](https://forms.gle/RDZ13m9Zf3jUKD2Q8)

フォームでは、お問い合わせ種別を選び、詳細をご記入ください。返信が必要な場合は、メールアドレス欄にご記入ください。

送信前に [プライバシーポリシー](/privacy-policy) をご確認のうえ、同意のうえ送信してください。

## お問い合わせ時のお願い

対応を早めるため、できるだけ次の内容を詳細欄に書いてください。

- 該当ページの URL
- 気になった箇所（見出し名、段落、コードなど）
- いまどうなっているか（表示・エラー文）
- 期待する修正内容や質問の背景
- 表示不具合の場合は、利用しているブラウザや端末

## 返信について

すべてのお問い合わせに必ず返信できるとは限りませんが、内容を確認し、必要に応じて対応します。

氏名、住所、電話番号、メールアドレス、APIキー、パスワード、アクセストークンなどの個人情報・秘密情報は送信しないでください。

## GitHub Issues（任意）

教材の誤りやリンク切れなど、**公開で報告してよい内容** は、GitHub Issues からも受け付けています。

- [GitHub Issuesで報告する](https://github.com/k5fujiwara/code-recipe/issues)

Issues に投稿された内容はインターネット上に公開されます。公開したくない相談は、上記フォームをご利用ください。
