# お問い合わせ

Code Recipe へのお問い合わせ、内容の修正依頼、掲載内容に関するご連絡は、以下の窓口からお願いいたします。

## お問い合わせ方法

現在のお問い合わせ窓口は、GitHub Issues です。

- [GitHub Issuesで問い合わせる](https://github.com/keigo-fujiwara/code-recipe/issues)

教材内容の誤り、リンク切れ、表現の改善案などがあれば、Issue としてご連絡ください。

GitHub Issues に投稿された内容は、インターネット上に公開されます。個人情報を含む内容や、公開したくない相談は投稿しないでください。

## お問い合わせ時のお願い

お問い合わせの際は、できるだけ以下の内容を添えてください。

- 該当ページのURL
- 気になった箇所
- 期待する修正内容
- 表示エラーの場合は、利用しているブラウザや端末

## 返信について

すべてのお問い合わせに必ず返信できるとは限りませんが、内容を確認し、必要に応じて対応します。

氏名、住所、電話番号、メールアドレス、APIキー、パスワード、アクセストークンなどの個人情報・秘密情報は送信しないでください。
